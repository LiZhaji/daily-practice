# 每日跟练 (daily-practice)

一个为个人健康锻炼设计的跟练主页：到点提醒直达、所有跟练内容收敛在一个入口、不用在各个平台之间跳来跳去。

**在线地址**：https://lizhaji.github.io/daily-practice/

## 解决什么问题

使用者每天有规律的锻炼需求，但跟练内容来自各个平台（B站、Keep、抖音等），内容杂乱、没有统一的提醒。希望：

1. **到点提醒**：每天到点自动提醒，点开通知直达当天该练的内容
2. **统一入口**：开练时所有内容收敛在一个页面，不在 App 之间来回切换
3. **混合内容**：有视频的跟视频（如八段锦口令视频），无视频的动作用倒计时 + 语音口令引导
4. **分时段**：不同内容分布在不同时间段（如早上八段锦、上午膝盖、晚上拉伸），每时段各提醒一次
5. **人人可编辑**：任何人打开链接，编辑的是自己设备上的一份清单（数据存本机浏览器，支持导出/导入备份）

## 使用方式

1. **手机访问**：Safari（iPhone）打开在线地址
2. **加到主屏幕**：Safari 分享按钮 → 添加到主屏幕，即可像 App 一样全屏使用
3. **编辑内容**：页面右上角「编辑」——增删时段、调整时间与每周重复日、添加动作（名称/秒数/组数/休息）或视频链接
4. **到点提醒**：在 iPhone 日历为每个时段建一条每天重复的事件，URL 栏填本页地址；到点弹通知，点开自动定位到当前该练的时段

## 文件结构

- `daily-practice.html` — 源文件（单文件应用，HTML + CSS + JS，无构建依赖）
- `index.html` — 同内容副本，供 GitHub Pages 根路径访问（两文件需同步修改）
- `CLAUDE.md` — 项目需求、技术决策与上下文，供 AI 助手（Claude Code）在新会话/新设备上接续工作

## 技术要点

- 单文件 Web 应用，无框架、无构建，直接部署到 GitHub Pages
- 每个访问者的数据存各自浏览器的 `localStorage`，互不干扰
- 动作计时用语音合成（`SpeechSynthesis`，中文口令）+ 提示音（Web Audio）
- B站视频支持页内嵌入播放（`player.bilibili.com` iframe），抖音/Keep 等链接提供跳转按钮
- 明暗双主题，适配手机刘海屏（safe-area），跟练时申请屏幕常亮（Wake Lock）
